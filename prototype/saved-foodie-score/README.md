# Saved + Foodie Score (working prototype)

Interactive HTML build of the Saved page and the Foodie Score page from the qlub+ design handoff.

- `index.html`: self-contained, images embedded. Open it in a browser.
- `index.template.html`: same page with `{{IMG:name}}` placeholders for the files in `assets/`.

Saved opens on **To Try** so untried dishes come first. The score card links to `#foodie-score`.
All numbers are placeholder data hard-coded in the page script.
